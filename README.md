# KobraMorda

Независимый Moonraker-совместимый мост для Anycubic Kobra X (с 4-слотовым
AMS-боксом): панель управления печатью в браузере, приём загрузок из
OrcaSlicer, живая камера, 3D-просмотр печати по слоям, история печатей,
таймлапсы, Spoolman и бот в Telegram.

## Запуск

Нужен установленный [Node.js](https://nodejs.org) (20 или новее).

**Просто запустить:** дважды кликните `KobraMorda.exe` в корне проекта. При
первом запуске он сам поставит зависимости и соберёт проект (откроется окно
с ходом установки, это займёт пару минут), затем сам откроет панель в
браузере. При следующих запусках просто откроет уже работающую панель или
поднимет мост заново, если он не запущен - без консоли.

Принтеры добавляются прямо в панели (шестерёнка → Принтеры → плюс), в
командной строке ничего указывать не нужно.

Другие способы запуска (на выбор):
- `KobraMorda.cmd` - то же самое, но с видимой консолью (удобно смотреть
  логи).
- `KobraMorda-hidden.vbs` + `install-autostart.ps1` - без консоли и с
  автозапуском при входе в Windows.

## Обновление

В панели: шестерёнка → Настройки → Обновления. Показывает, есть ли новые
коммиты в этом репозитории, и одной кнопкой подтягивает их, пересобирает
проект и перезапускает мост - печать на принтере при этом не прерывается.

Обновление доступно только если папка запущена из git-клона этого
репозитория (а не просто скачанного zip-архива) и требует установленный
`git`.

## Разработка

```
cd backend  && npm install && npm run build   # или npm run dev для авто-пересборки
cd frontend && npm install && npm run build
node backend/dist/server.js
```

Пересобрать `KobraMorda.exe` (после правок `launcher/Launcher.cs`):
`powershell -File launcher/build.ps1` - использует компилятор C#,
входящий в состав любой Windows-системы, ничего дополнительно ставить не
нужно.
